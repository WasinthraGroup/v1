Chonnabot (ชีวิตในชนบท)

Platform: Roblox Category: Simulation / Educational Status: Active

สัมผัสวิถีชีวิตที่เรียบง่ายแต่เปี่ยมด้วยเสน่ห์ของชนบทไทย ผ่านโลกเสมือนจริงบนแพลตฟอร์ม Roblox

"ชนบท" คือโปรเจกต์ที่เราตั้งใจจำลองบรรยากาศบ้านสวนในต่างจังหวัด ทั้งบ้านไม้ใต้ถุนสูง ทุ่งนาสีทอง และวิถีชีวิตการเกษตรแบบดั้งเดิม เพื่อให้ผู้เล่นได้พักผ่อนและเรียนรู้วัฒนธรรมไทยในรูปแบบที่สนุกสนานและเข้าถึงง่าย

Highlight Features

  • ระบบการทำนาและเกษตรกรรมพื้นบ้าน
  • สถาปัตยกรรมไทยประยุกต์ที่สมจริง
  • บรรยากาศ Day/Night Cycle ที่สวยงาม
